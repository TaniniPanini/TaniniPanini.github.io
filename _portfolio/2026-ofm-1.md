Manu is writing an ebook about sunglasses, but because of a problem with his $\LaTeX$ compiler, the $N$ pages of the pdf appear in a completely random order. Thankfully, Brigitte has vibe-coded some software to help Manu fix his pdf. Her program can do two different actions:

- Reverse the order of the pages in the pdf, putting the first page in the last position, the second page in the penultimate position, and so forth, up to putting the last page in the first position.

- If the first page is page number $M$, the program can order the $M$ first pages of the pdf, but in **decreasing** order.

For instance, if the order of the pages is currently $3, 4, 2, 5, 1$ then choosing the first action would give $1, 5, 2, 4, 3$, whilst choosing the second action would instead give $4, 3, 2, 5, 1$.

Prove that even with this terrible program, Manu can eventually put his pdf back in the right order.
